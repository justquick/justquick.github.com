<div id="google-chartwrapper">
  <div class="github-widget" data-repo="justquick/google-chartwrapper"></div>
  <div class="inline-image"><img src="http://chart.apis.google.com/chart?chds=0,100&chd=t:100.0,80.0,60.0,30.0,30.0,30.0,10.0&chs=150x75&cht=v" alt="Sample chart generated by GChartWrapper" width="150"></div>
  <p>GChartWrapper was my first major open-source project — a lightweight Python wrapper around the Google Charts Image API. I began writing it in college and was pleasantly surprised to find it was adopted by <a href="https://code.google.com/archive/p/google-chartwrapper/wikis/WhoUsesTheWrapper.wiki">a wide variety of projects across the internet</a>. The library makes it straightforward to produce charts like the one shown here.</p>
</div>

<div id="django-activity-stream">
  <div class="github-widget" data-repo="justquick/django-activity-stream"></div>
  <div class="inline-image"><img src="https://django-activity-stream.readthedocs.io/en/latest/_static/logo.jpg" width="150" alt="django-activity-stream logo"></div>
  <p>My most widely adopted project, with thousands of daily downloads from PyPI. django-activity-stream is a Django implementation of the <a href="http://activitystrea.ms/">Activity Streams protocol</a>. I have contributed to specification development alongside the <a href="https://www.w3.org/Social/WG">W3C Social Web Working Group</a> and delivered a <a href="https://www.youtube.com/watch?v=R_tyN8bNe4A">talk on the topic at DjangoCon US 2014</a>. Full <a href="https://django-activity-stream.readthedocs.io/en/latest/">documentation, examples, and concepts are available on the project site</a>.</p>
</div>
<hr>

<div id="python-googlevoice">
  <div class="github-widget" data-repo="justquick/python-googlevoice"></div>
  <div class="inline-image"><img src="https://storage.googleapis.com/google-code-archive/v2/code.google.com/pygooglevoice/logo.png" width="150" alt="python-googlevoice logo"></div>
  <p>A Python implementation of the Google Voice API — reverse-engineered from browser traffic since no official API existed at the time. The project sparked an ongoing back-and-forth with Google as they added successive authentication layers to block unofficial access. I circumvented the first round, but subsequent security hardening made further effort impractical, and the project is now retired.</p>
</div>
